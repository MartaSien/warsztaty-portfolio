# VSCode w 5 min

## Przydatne skróty klawiszowe
`Windows` `Linux`

- więcej na: [vscode docs](https://code.visualstudio.com/docs/reference/default-keybindings)

### Edycja kodu

| Skrót | Działanie |
| --- | --- |
| ++ctrl+s++ | Zapisuje aktualny plik |
| ++ctrl+z++ | Cofa ostatnią zmianę |
| ++ctrl+shift+z++ | Przywraca cofniętą zmianę |
| ++alt+arrow-up++ / ++alt+arrow-down++ | Przenosi aktualną linię kodu w górę lub w dół |
| ++shift+alt+arrow-down++ | Kopiuje aktualną linię poniżej |
| ++ctrl+slash++ | Dodaje lub usuwa komentarz w linii |

### Wyszukiwanie, nawigacja, pozostałe

| Skrót | Działanie |
| --- | --- |
| ++ctrl+f++ | Szuka tekstu w aktualnym pliku |
| ++ctrl+shift+f++ | Szuka tekstu we wszystkich plikach projektu |
| ++ctrl+p++ | Szybko otwiera plik po nazwie |
| ++ctrl+shift+p++ | Otwiera paletę poleceń |
| ++ctrl+grave++ | Otwiera lub zamyka terminal |
| ++ctrl+k++ potem ++ctrl+s++ | Otwiera listę skrótów klawiszowych |
