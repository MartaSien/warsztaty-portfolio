# Introduction

These are notes for a course on creating a personal portfolio using a static website generator.

!!! info "During the course, you will learn"


    - How to generate your own static website.
    - How to publish and maintain it for free.
    - How to automate to verification and publication of changes to your website.


## Course organization


- Live classes
- Location: [Hackerspace Trójmiasto](https://hs3.pl/)
- Free admission, but I encourage you to support [Hackerspace Trójmiasto](https://hs3.pl/zasoby/czlonkostwo/) :heart:
- :clock: Classes take place every other Thursday of the month, from `17:00 - 20:00`
- Notes for upcoming classes will be gradually published here
- Please direct all questions to [Discourse](https://kb.hs3.pl/t/warsztaty-z-tworzenia-strony-internetowej-personalnego-porftolio/1023)

=== "Lesson 1"
    We will install the programs needed for the workshops.
    We will create our first static website using the [`Pelican`][pelican] generator.


=== "Lesson 2"
    We will learn what Git is and continue developing our website.
    We will explore the capabilities of the [`Pelican`][pelican] generator.


=== "Lesson 3"
    We will learn what [GitHub][github] is and create a free account.
    We will publish our repository there.


=== "Lesson 4"
    We will explore the capabilities of [`GitHub Actions`][ghactions] — a powerful automation tool.


=== "Lesson 5"
    We will create a static website using the [`Zensical`][zensical] generator.


=== "Lesson 6"
    We will get to know [Figma][figma] — a tool that makes website design easier.


=== "Lesson 7"
    Using everything we have learned so far, we will continue developing our portfolios.


## Technologies and tools you will use


* [`Zensical`][zensical] — Static website generator
* [`Pelican`][pelican] — Static website generator
* [`GitHub Actions`][ghactions] — Automation tool
* [`git`][git] — The most popular version control system
* [`Python`][python] — A programming language that is easy to start with
* [`Visual Studio Code`][vscode] — Code editor (often referred to as an “IDE” — Integrated Development Environment)
* [`Figma`][figma] — Website design tool


## How to prepare?


* [x] Bring your own laptop
* [x] It should meet the minimum requirements for installing [Python][python] and [Visual Studio Code][vscode]
* [x] Windows is the recommended operating system, but we can work with other systems too!
* [x] During the classes, you will need to create a free [GitHub][github] account
* [x] You do not need any prior programming experience — we will learn together from the basics
* [x] Don’t be afraid to make mistakes — in programming, they are a great teacher. Ask questions and have fun! :smile:
