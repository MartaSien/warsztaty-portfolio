# VSCode in 5 min


## Useful keyboard shortcuts
`Windows` `Linux`


- More at: [VSCode docs](https://code.visualstudio.com/docs/reference/default-keybindings)


### Code editing


| Shortcut | Description |
| --- | --- |
| ++ctrl+s++ | Saves the current file |
| ++ctrl+z++ | Undoes the last change |
| ++ctrl+shift+z++ | Redoes an undone change |
| ++alt+arrow-up++ / ++alt+arrow-down++ | Moves the current line of code up or down |
| ++shift+alt+arrow-down++ | Copies the current line below |
| ++ctrl+slash++ | Adds or removes a line comment |


### Search, navigation, and more


| Shortcut | Description |
| --- | --- |
| ++ctrl+f++ | Searches for text in the current file |
| ++ctrl+shift+f++ | Searches for text across all project files |
