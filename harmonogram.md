#  Harmonogram zajęć

Każdy punkt to jedno spotkanie ~3 godziny

## Przygotowanie środowiska i nauka git
- instalacja Visual Studio Code
- instalacja git
- dlaczego programiści używają git?
- zaznajomienie się z używaniem VS Code
- tworzymy repo lokalnie (np. inicjujemy je z README.md)
- tworzymy pierwszy commit
- tworzymy i tłumaczymy plik .gitignore
- tworzymy nowy branch i robimy na nim zmiany
- merge'ujemy zmiany do brancha głównego
- revertujemy zmianę, której nie chcemy mieć w repo
- sprawdzenie czy uczestnicy zrozumieli koncepcję git-a. Jeśli nie są zbyt przytłoczeni to można zacząć wcześniej z Pelicanem.

## Nauka [Pelican](https://getpelican.com/)
- postawienie pierwszej strony z generycznym theme w naszym wcześniej utworzonym repo
- bawimy się generycznym theme

## Nauka GitHub-a i jak przenieść Twoje repo na remote
- pushujemy repo, które lokalnie stworzyliśmy na poprzednich zajęciach (publiczne repo)
- demonstrujemy jak jeden deweloper może spushować coś na remote, a drugi deweloper może wtedy tą zmianę spullować
- pokazujemy jak zabezpieczyć nasz branch główny przed niechcianymi zmianami
- tworzymy pull request naszej zmiany i pokazujemy jak ładnie github wszystko pokazuje
- pokazujemy wtyczkę GitLens do VS Code

## Nauka GitHub Actions
- konfigurujemy repo pod GitHub Actions
- tworzymy pipeline dla naszej pelicanowej stronki i publikujemy ją
- jak zdążymy, pokazujemy co można jeszcze dodać, np. dependabot, linter
